Machine Switcher
Switch between your bb machines in one tap from the sidebar, the palette, or `bb machines`.
Configuration
Mobile deep-link path
Appended to a machine's URL when switching from the mobile app. Must be under /settings, /threads or /projects so the native app claims the link.
/settings/general
Machine names and colours
Nickname and colour each bb machine as it appears in the switcher.
The current machine is detected from bb connect. Nicknames and colours are stored on this machine only.
